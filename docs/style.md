# Style

Новый код должен быть читаемым и небольшим по ответственности. Не следует
расширять уже крупные orchestration-модули, если новую логику можно вынести в
отдельный модуль с узким интерфейсом и отдельными тестами.

Форматирование пока не является жёстким CI-gate. Ruff используется прежде всего
для ошибок корректности, чтобы внедрение quality tooling не создавало огромный
style-only diff.
