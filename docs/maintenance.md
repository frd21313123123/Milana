# Maintenance

## Перед релизом

1. Обновить зависимости в отдельной ветке.
2. Запустить `python scripts/check_project.py`.
3. Убедиться, что CI зелёный на Windows и Ubuntu.
4. Не включать в коммит `.env`, session-файлы, базы данных и runtime-логи.

## Крупные рефакторинги

Большие модули лучше дробить небольшими совместимыми PR. Сначала вынести чистые
структуры и helpers, затем orchestration, после каждого шага запускать полный
набор тестов. Это уменьшает риск поломать устойчивый outbox, IPC или Telegram
recovery в одном большом изменении.
