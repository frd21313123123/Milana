# Dependencies

Runtime-зависимости остаются в `requirements.txt`, инструменты разработки в
`requirements-dev.txt`. Dev-файл намеренно минимальный, чтобы установка локальных
проверок и CI занимала меньше времени.

Dependabot раз в неделю предлагает обновления Python-пакетов и GitHub Actions.
Обновления следует принимать только после полного CI.
